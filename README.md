## Reflection

Through this activity, I practiced solving algorithmic problems using C++ and learned how to think about both correctness and efficiency. The problems covered arrays, matrices, vectors, strings, and hash maps, which helped me understand how different data structures can be selected according to the problem requirements.

I learned the importance of analyzing time and space complexity before implementing a solution. For example, the Diagonal Difference problem can be solved by traversing only the required diagonal elements instead of performing unnecessary operations. In Dynamic Array and Sparse Arrays, efficient data structures help organize and retrieve information effectively. The Time Conversion and Compare the Triplets problems helped strengthen my understanding of string manipulation, conditions, loops, and direct implementation.

I also learned that passing sample test cases is not enough; solutions should be tested against different inputs and should handle edge cases correctly.

Submitting the solutions on HackerRank gave me practical experience with an online coding platform, while maintaining the solutions on GitHub helped me organize my work into a portfolio.

Overall, this activity improved my confidence in algorithmic problem solving and made me more aware of writing solutions that are both correct and efficient. I also practiced debugging by tracing sample inputs step by step and checking where my logic could be improved. Before finalizing each solution, I reviewed its time and space complexity and tested additional edge cases. Organizing these solutions together gives me a clearer portfolio of my learning and progress.
